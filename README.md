🌱 EcoEducation – SDG 7 Learning Mobile App (Project 1) 🌱

EcoEducation is a mobile application developed to support Sustainable Development Goal (SDG 7: Affordable and Clean Energy) by providing an interactive and engaging learning platform about environmental awareness, sustainability, and clean energy education.

This project focuses on making learning more accessible and engaging through a mobile application that promotes knowledge about renewable energy and eco-friendly practices.

📱 Key Features of EcoEducation:

Clean and user-friendly interface
5-screen navigation system
Educational content about sustainability and clean energy
Interactive learning experience
Add and display learning items

🎯 Project Objectives:

To promote awareness of sustainable and clean energy
To support SDG 7 through digital learning
To encourage interactive mobile-based education
